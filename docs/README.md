# Documentation

The [public contract](CONTRACT.md) defines Almanac's models, conventions, API behavior, accuracy, fixture evidence, and parity rules. [Scope](SCOPE.md) records supported behavior and deliberate boundaries. The [library comparison](comparison.md) sets Almanac beside other Sun and Moon libraries. [Contributing](../CONTRIBUTING.md) contains the repository layout, implementation constraints, checks, performance harness, and release process. Proposed work belongs in [GitHub issues](https://github.com/openwatersio/almanac/issues).

The migration guides cover [SunCalc](migrating-from-suncalc.md), [Astronomy Engine](migrating-from-astronomy-engine.md), and [Solar](migrating-from-solar.md). Their TypeScript and Swift examples run in the test suites. The [README](../README.md#javascript-module-loading) explains ESM and CommonJS loading.
