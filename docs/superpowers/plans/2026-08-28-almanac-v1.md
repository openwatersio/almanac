# Almanac v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Twin Swift + TypeScript sun/moon engine — positions, rise/set/twilight, moon phase, lunar eclipses — validated against JPL Horizons, USNO, and Espenak fixtures.

**Architecture:** Four layers (time → positions → transforms → event searches), translated from Astronomy Engine at pinned commit `865d3da7d8112bbc7911238052c6af4aaf877181`, held together by a shared fixture corpus. TypeScript leads each layer; Swift follows immediately.

**Tech Stack:** TypeScript (ESM, zero runtime deps, vitest), Swift (SwiftPM, XCTest), Node ≥20 `.mjs` fixture scripts (built-in `fetch`, zero deps), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-28-almanac-v1-design.md`

## Global Constraints

- Supported interval: `1950-01-01T00:00Z ≤ t < 2101-01-01T00:00Z`; outside → typed out-of-range error. Never a degraded answer.
- All angles degrees; azimuth from true north through east [0,360); RA of date [0,360); moon distance km; sun distance AU.
- API instants are platform Dates (UTC-shaped, ms precision), treated as UT1; TT = UT1 + ΔT (Espenak–Meeus).
- Zero runtime dependencies in both packages. ESM only on the TS side.
- Tolerances (fixture metadata is authoritative): sun ≤ 1′, moon ≤ 1′, event times ≤ 60 s, eclipse peak/contacts ≤ 60 s. Alt/az vs Horizons: ≤ 1′ for altitudes > 10° (refraction models diverge near the horizon; event accuracy is covered by USNO fixtures).
- **Translation rule:** upstream source is `source/js/astronomy.ts` at the pinned sha (`UPSTREAM=https://raw.githubusercontent.com/cosinekitty/astronomy/865d3da7d8112bbc7911238052c6af4aaf877181/source/js/astronomy.ts`). NEVER retype coefficient tables from memory — download the file and copy them. Cite the upstream function in a comment above each translated function.
- Fixture scripts run offline from committed raw responses; only `refresh-*.mjs` scripts touch the network, run manually once.
- Commit after every green task. Do not push tags until Task 19.

```ts
export interface Observer { latitudeDeg: number; longitudeDeg: number; elevationM?: number; }
export class AlmanacOutOfRangeError extends RangeError {
  constructor(msg = 'time outside supported interval 1950-01-01T00:00Z ≤ t < 2101-01-01T00:00Z') { super(msg); this.name = 'AlmanacOutOfRangeError'; }
}
export const SUPPORTED_MIN = Date.UTC(1950, 0, 1);
export const SUPPORTED_MAX = Date.UTC(2101, 0, 1);
export function assertSupported(d: Date): void {
  const t = d.getTime();
  if (!Number.isFinite(t)) throw new RangeError('invalid Date');   // validation, not out-of-range
  if (t < SUPPORTED_MIN || t >= SUPPORTED_MAX) throw new AlmanacOutOfRangeError();
}
/** Cross-port rule: all instants are integer epoch ms (JS Dates already are). */
export function assertObserver(o: Observer): void {
  const { latitudeDeg: lat, longitudeDeg: lon, elevationM: elev = 0 } = o;
  if (!(lat >= -90 && lat <= 90)) throw new RangeError(`latitudeDeg out of range: ${lat}`);
  if (!(lon >= -180 && lon <= 180)) throw new RangeError(`longitudeDeg out of range: ${lon}`);
  if (!(elev >= -500 && elev <= 10000)) throw new RangeError(`elevationM out of range: ${elev}`);
}
```
`src/index.ts`: `export * from './types.js';`

```swift
import Foundation

public enum AlmanacError: Error, Equatable {
    case outOfRange
    case invalidObserver(String)
    case invalidArgument(String)
}

/// Cross-port rule: instants are integer epoch milliseconds. Foundation Dates
/// carry sub-ms precision; floor it away before any math or returned result.
public func normalized(_ d: Date) -> Date {
    Date(timeIntervalSince1970: (d.timeIntervalSince1970 * 1000).rounded(.down) / 1000)
}

/// 1950-01-01T00:00Z (incl.) … 2101-01-01T00:00Z (excl.) — the fixture-evidence interval.
public let supportedMin = Date(timeIntervalSince1970: -631_152_000)
public let supportedMax = Date(timeIntervalSince1970: 4_133_980_800)

public func assertSupported(_ d: Date) throws {
    guard d.timeIntervalSince1970.isFinite else { throw AlmanacError.invalidArgument("non-finite Date") }
    guard d >= supportedMin, d < supportedMax else { throw AlmanacError.outOfRange }
}

public struct Observer: Sendable {
    public let latitudeDeg: Double
    public let longitudeDeg: Double
    public let elevationM: Double
    public init(latitudeDeg: Double, longitudeDeg: Double, elevationM: Double = 0) throws {
        guard (-90...90).contains(latitudeDeg) else { throw AlmanacError.invalidObserver("latitudeDeg \(latitudeDeg)") }
        guard (-180...180).contains(longitudeDeg) else { throw AlmanacError.invalidObserver("longitudeDeg \(longitudeDeg)") }
        guard (-500...10000).contains(elevationM) else { throw AlmanacError.invalidObserver("elevationM \(elevationM)") }
        self.latitudeDeg = latitudeDeg; self.longitudeDeg = longitudeDeg; self.elevationM = elevationM
    }
}
```

- Algorithm (extrema-bracketed — a fixed grid can miss tangent/grazing events): per body per UT day, locate the altitude extrema (transit maximum via hour-angle zero; minimum ≈ 12 h away, sun; moon extrema from its ~24h50m cycle), then solve each monotonic segment between consecutive extrema by bisection to < 1 s against each target. Probes beyond window edges are clamped to the supported interval. Iteration cap 60 bisections per root (assert unreached).
